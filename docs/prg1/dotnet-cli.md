# Polecenia:
| Polecenie | Przykład | Opis |
| :--- | :--- | :--- |
|<mark> *dotnet* --version* </mark> | dotnet --version | Sprawdzenie zainstalowanej wersji zestawu .NET SDK. |
| <mark>*dotnet --list-sdks* </mark> | dotnet --list-sdks | 	Wyświetlenie wszystkich dostępnych wersji SDK. |
| <mark>*dotnet new list* </mark> | dotnet new list | Wyświetlenie dostępnych szablonów projektów.|
| <mark>*dotnet new console* </mark>| dotnet new console | Utworzenie aplikacji konsolowej w bieżącym katalogu.
|<mark>*dotnet new console -n*</mark>|	dotnet new console -n MyApp	| Utworzenie aplikacji konsolowej w katalogu MyApp. |
|  <mark>*dotnet restore* </mark>| dotnet restore |  Pobranie zależności wymaganych przez projekt. |
| <mark>*dotnet build* </mark>| dotnet build | Kompilacja projektu i odczyt komunikatów o błędach. |
| <mark>*dotnet run* </mark>| dotnet run --project MyApp  | Zbudowanie i uruchomienie wskazanego projektu.  |
| <mark>*dotnet clean*</mark>| dotnet clean  | Usunięcie plików wygenerowanych podczas kompilacji. |
